The Basics
Force
Effects
See It
Happen!
A force is a push or pull that can change motion.You may not see the force — but you can measure what it does.
01
Start Motion

An unbalanced force can make an object at rest begin moving.

02
Change Speed

A force can speed an object up or slow it down.

03
Change Direction

A sideways force can redirect an object without stopping it.

04
Balance Out

Equal opposing forces can cancel, leaving motion unchanged.

Key Idea

Net Force= All Forces
Combined

When the net force is zero, motion does not change. When it is not zero, motion changes.
