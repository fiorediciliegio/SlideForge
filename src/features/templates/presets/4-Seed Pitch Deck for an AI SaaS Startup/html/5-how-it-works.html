04  /  How it works

Four stages, one audited loop

The agent never improvises against a live system. It plans, checks the plan against policy, executes with typed tools, and writes a trace your auditor can read.

STAGE 01 Ground Pull the account, entitlement, order and history into a single typed context object. ~1.2s
STAGE 02 Plan Draft an ordered action plan and score confidence against 90 days of resolved tickets. ~3.4s
STAGE 03 Act Execute typed tool calls with per‑action spend caps; route anything over the line to a human. ~9s median
STAGE 04 Prove Emit an immutable trace, push outcome metrics, and feed corrections back into policy. continuous
