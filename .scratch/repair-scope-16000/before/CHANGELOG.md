记录 PPT App 的功能需求、后端逻辑调整和明显严重的问题修复；简单的界面展示或样式调整不单独记录。每周整理时按版本号追加记录，最新版本置于顶部；日期使用 `YYYY-MM-DD` 格式。

## 未发布

日期：2026-11-14

### 新增功能

- 在线版面检查、预览和 PDF/PPTX 导出改为独立引擎任务，业务与引擎通过固定输入快照及任务 ID 协作，支持分机部署。
- 新增持久队列、用户公平调度、租约隔离、取消及失联最多一次恢复；同版本有效结果复用。Web/WPS 支持异步导出状态，Go 先幂等扣点再发布下载。
- Python Brain 默认支持 5 个项目并发；单纯等待引擎排队不计有效执行时间，本机默认限制 1 个重型引擎作业。

- Web 接入 Python 单总控 Agent：自主选择资料读取、规划、生成、检查和定向修订工具，结合程序报告与截图完成质量闭环。
- 新增“直接生成”和“先确认大纲”，支持固定、范围和自动页数；大纲可自动保存、修改标题/要点、拖动排序及增删页面。
- 新增模型成本与有效执行时间预算，支持追加预算；未知模型调用须明确同意后才重试，等待用户和排队不计时。
- 项目持久保存资料、品牌/模板、已确认约束、页面版本与修改记录；可续改、单页回退，并渐进迁移旧作品。
- 新增场景识别与用户更正，结构调整建议须进入可编辑大纲确认；默认交付预览，明确授权后才导出。

### 体验优化

- Harness 新增检查返工专用 `revise_pages`：一次提交2至6页已明确的独立修订，并发保持默认2。每页使用各自指令/候选与持久回执，成功页保留、失败页不覆盖有效版本，预算/未知调用/取消停止后续派发；批次恢复使用固定输入，提交前核对本页版本与项目约束，防止旧候选覆盖新编辑。
- 总控输出上限由4096调整为8192，费用预留同步采用同一上限；单页输出12000、思考强度、每页两次返工及质量闸门不变。两项变更后的测评按综合效果报告。
- Harness 按当前版本的检查缺口自动推进：初检依次为程序版面、全稿内容、分批视觉（最多4页），内容与视觉仍由模型分开评审。阶段问题收齐后修订，复用未改页有效证据，在一轮修订后补齐当前全稿复核，减少模型为取证、调度和收尾单独决策的往返。
- 质量闸门通过后自动完成已有授权的导出及交付收尾，沿用当前修订的持久完成回执；追加检查须说明具体问题，预算、取消、恢复与每页返工上限不变。
- 同回合读取扩展到资料正文、当前页面和页面历史，可混合最多4项并顺序执行，保留原page_ids数组能力。明确返回未生成/不存在的页面ID，已删除页面仍可查询历史；读取回执标注项目修订，版本变化后停止旧批次并重新建立当前版本依据，旧结果继续保留。
- Harness 支持同回合顺序读取最多4个独立资料正文分块，每项保留原4000字符上限；普通单项错误不阻断其他读取，超限批次明确拒绝。逐项保存读取结果，成功及普通错误均有持久回执，消息检查点写入失败后恢复也不会重读明确失败项；取消、预算暂停和执行失效停止剩余读取。其他工具保持单工具回合。
- 任务进度采用带业务 Key 的 SSE，断线后恢复快照；大纲保存冲突时保留本地编辑并阻止确认旧版本。
- 修改页面后重查受影响页面并复核全稿，未改页有效检查可复用；服务中断保留已有产物，用户点击继续恢复。

### 问题修复

- 修复附件提取接口仍按 2 MiB 拒绝正常 PDF 等附件上传，导致创建失败并显示 terminated 或连接重置的问题；创建失败不再统一附加检查 API Key 与点数的提示。
- 修复导出取消后无法重试、旧付费回执升级后重复扣点、扣费身份被缓存淘汰及零余额无法取回付费回执的问题。
- 固定快照的 PDF/PPTX 加载边界限制外部资源；引擎就绪检查验证队列连接，模型已生成内容不会因引擎提交失败而再次调用付费模型。

- 修复导出恰好扣完余额后，已付费文件仍因余额不足而无法下载的问题；文件读取按有效凭据及文件归属鉴权。

- 修复视觉检查将截图Base64字节误计为输入token，导致模型费用未到上限就暂停：DeepSeek图片按官方每图1024 token上界预留，实际费用仍按usage结算；真正不足时显示剩余可用金额和下一次调用所需预留。

- 续改不再仅用初始大纲重生成，改用当前页面、有关修改要求及品牌/模板快照；手动保存、换肤、WPS回传进入版本链。
- 修复取消后迟到结果覆盖状态、并发预算超额预留以及草稿保存与确认竞态；Go 保存失败不删除旧任务快照。
- 四进程 dev 自动加载项目 `.env` 并优先使用项目已有 Python 虚拟环境，避免落到缺少 Pillow 的系统解释器。
- 后台授权导出按作品归属幂等扣点，无须持久保存业务 Key；下载继续使用原有鉴权边界。
- 修复旧 HTTP 创建接口遗漏正文资料 `source_text`，使正文资料与附件提取内容共同进入生成上下文。
- 修复版本工作区PDF导出的页面路径；已完成的页面及时进入预览，取消后未开始的排队导出不会执行或扣点。
- 修复大纲多标签覆盖、恢复时丢失确认暂停、生成完成后编辑按钮未启用，以及手动保存后续改使用旧版本的问题；已落盘模型响应先复用结算，避免重复调用。

## v2.0.8 更新日志

日期：2026-09-24

### 新增功能

- **单页配图**：大纲编辑和单页重新生成支持按关键词搜索图片、批量选择及上传本地配图，并展示图片处理进度。生成页面时，AI 可直接参考所选原图，更好地理解图片内容。
- **云端字体**：人工编辑页面时，可以浏览、下载并使用云端字体，同时完善中文等字体在 PPTX 导出中的处理。

### 体验优化

- **大纲生成与编辑**：大纲生成和 AI 改写改为分段处理，完善失败重试和进度展示，优化大纲详情布局与标题编辑体验。
- **界面交互**：调整页面精修控件和状态提示；语言切换改为地球仪下拉菜单，并完善中、英、日、德四种语言的相关文案。
- **作品加载与同步**：减少“我的作品”的重复加载，完善作品云端同步状态展示。

### 问题修复

- 修复长大纲内容过多导致的传输失败。
- 修复生成过程中预览闪烁、短暂空白的问题。
- 修复云端作品较多时，“我的作品”列表加载超时的问题。
- 完善页面生成和研究流程的自动重试，避免个别无效图片阻断流程，并优化超时提示。
- 修复作品删除、字体重复及 PPTX 导出等待时间不足等问题。
