## 本机启动

```powershell
Set-Location 'D:\SlideForge'
npm.cmd run dev
```

打开 `http://localhost:8080/app`，终端保持运行。Ctrl+C关闭本次四进程。启动器加载项目 `.env`，已存在的进程环境变量优先；自动选择仓库 `.tooling` 内的Go和Python。模型Key放在 `.env`；网页填入网关签发的业务Key。

新 Harness 要求工具调用和图片输入均可用，且配置模型成本单价；详见[部署手册](../../docs/deployment.md)。本轮没有新增全局依赖或更换用户密钥。

## 独立审查及修复

一次独立上下文只读审查报告9项Important，无Critical或Minor；逐项确认后修复，没有追加第二轮审查。

| 发现 | 处理与验证 |
|---|---|
| 远端SSE修订号覆盖本地草稿基准 | 保存/确认使用本地draft修订；浏览器rev1本地稿遇到rev2远端稿保持409与本地文字，RED→GREEN |
| 规划落盘后恢复丢失确认暂停 | 正常/恢复共用完整计划回执，生成工具检查确认；agentRecoveryBoundaries RED→GREEN |
| 响应已落盘未结算仍被重新调用 | 继续前按run/call定位响应并结算，确实缺结果才请求重试同意；agentRecoveryBoundaries RED→GREEN |

| 快页等待慢页，预算暂停时无预览 | 模型生成保持并行，成功候选即时串行提交；四进程在慢页等待期间读取快页，RED→GREEN |
