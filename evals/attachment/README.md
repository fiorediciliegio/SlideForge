# 附件与 Outline Eval 数据集

本目录保存 PPT 附件处理和固定输入 Outline Eval 的测试数据。测试数据不得进入 `src/`、生产 Executa 或 UI bundle；每次运行产物应保存到 `.eval-results/`，不得回写到本目录。

## 目录与用途

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| `附件-测试用例.xlsx` | 原始测试用例工作簿 | Mode A、测试用例 R1 与固定输入 Outline 用例的来源说明。 |
| `datasets/测试用例模式A/` | 50 个 MD、TXT、DOCX 附件 | Mode A：从用户 Brief 与附件开始，运行到 `Attachment Context` 后停止。 |
| `datasets/ppt测试样例数据/` | 43 个跨格式附件 | 附件解析横向回归集；使用统一 Brief，覆盖不同格式、大小和表格规模。 |
| `datasets/测试用例R1/` | 早期综合案例附件 | 作为人工复核和扩展用例来源；其中包含当前前端上传入口未开放的格式，不作为默认附件批测集。 |
| `datasets/B-NEW/fixtures/` | 50 组固定 Brief、Attachment Context、Requirements 与 Gold | Mode B：直接评测 Outline，不重新上传或解析附件。 |

`ppt测试样例数据` 的 43 条附件构成为：TXT 6、MD 5、DOCX 6、DOC 3、XLSX 6、XLS 5、PDF 6、CSV 6。

## 运行边界

- Mode A 仅运行：Brief + 附件 → 预检 → 路由 → `Attachment Context`。
- Mode A 对应 `attachment-context-created` 截止点；附件也可用于需求、研究、大纲及完整 PPT 批量测试。导入 JSON 可保留已有 Host Upload 引用，或按文件名配对本地附件后上传。
- Mode B 仅运行：固定 Brief + 固定 `Attachment Context` + 固定 Requirements → Outline。
- Mode A 与 Mode B 是相互独立的评测；Mode B 不得从 Mode A 的某次运行结果中读取输入。
- 用例配置应保留稳定 ID、输入附件、固定 Brief、期望策略和人工复核说明。
- 批测报告应记录解析状态、warning、模型重试、预检耗时、附件处理总耗时、平台消耗及最终上下文。

## 当前能力与验收覆盖

| 能力 | 当前实现判断 | 验收结论 |
| --- | --- | --- |
| Excel 图表 | `.xlsx` 能识别图表对象并给 warning；不读取图表语义、数据系列或视觉内容；`.xls` 无同等识别保障 | 未支持 |
| 真实公式及公式计算结果 | 完整读取真实公式、公式结果读取已有缓存值；不计算公式。无缓存值时 warning | 不支持公式计算 |
| 多 Sheet | 读取所有可见 Sheet，保留 Sheet 边界 | 已实现，未用真实多 Sheet 样例验证 |
| 隐藏 Sheet | 能识别，但明确排除其内容并 warning | 已实现“排除”，不支持读取 |
| 合并单元格 | 统计合并区域数量；不保留完整合并布局语义 | 部分支持 |
| Excel 图片 | `.xlsx` 可识别图片并 warning；不 OCR、不理解图片 | 未支持视觉读取 |
| Excel 批注、外链 | 没有明确提取、保留或 warning 逻辑 | 未支持 |
| Word 真表格 | `.docx` 正文表格会转为 Markdown；嵌套表格会标记 partial | 已实现，未用真表格样例验证 |
| Word 标题样式 | 依赖 Mammoth 的正文转换，可能保留部分语义；无明确标题样式校验或指标 | 部分支持，未验证 |
| Word 页眉页脚 | `.docx` 会提取文字 | 已实现，未验证 |
| Word 脚注/尾注 | `.docx` 会提取文字 | 已实现，未验证 |
| Word 图片 | 图片可保存为附件资源，并 warning；不 OCR、不理解图像内容 | 部分支持 |
| Word 批注、修订 | 无明确检测、提取或 warning 逻辑 | 未支持 |
| Word 外链 | `.docx` 正文超链接可保留文字和 URL | 已实现，未验证 |
| 损坏文件 | 解析异常会成为通用 `parse_failed` | 有失败处理，无细分识别 |
| 加密文件 | 预计会解析失败，但没有专门“已加密”识别和提示 | 未支持专项处理 |
| 空文件 | 上传阶段直接拒绝 0 字节文件 | 已实现 |
| 错误扩展名 | 不在白名单的后缀会拒绝；但“内容伪装成允许后缀”不做可靠文件签名校验 | 部分支持 |
| 超限文件 | 单文件 25 MiB、当前附件总量 100 MiB，上传阶段拒绝 | 已实现 |
| 并发上传 | 前端多选后是逐个串行上传；没有并发安全性验证 | 未验证 |
| 上传失败重试 | 临时网络/5xx 等存储错误自动最多重试 3 次；附件摘要模型也最多重试 3 次 | 已实现，未压测 |
| 取消上传/解析 | 批测流程支持取消；普通附件上传没有可靠的“中途终止上传”能力 | 部分支持 |
| 网络中断 | 可对可重试错误重试；不支持断点续传、恢复已中断的大文件上传 | 部分支持 |
| 附件提示注入 | 附件摘要和后续需求提炼 Prompt 已规定“附件仅为参考，不能作为指令” | 已实现，未做对抗样例验证 |
| 敏感数据 | 仅对日志中的签名 URL、token 等传输凭据做脱敏；不检测、不屏蔽、不脱敏附件正文中的 PII/敏感业务数据 | 未支持 |

## 维护约定

- 新增测试文件先归入已有数据集；只有覆盖维度明显不同才新建数据集。
- PDF 专项回归包含 CMap 中文文字、长文本、表格、图片图表和复杂边界文件；新增或调整时，应在用例清单中标明预期是否触发 OCR。
- `.DS_Store`、批测 workspace、运行报告、压缩结果包和临时输入文件不应提交到数据集目录。
