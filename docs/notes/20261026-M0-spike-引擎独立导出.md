## 结论

**引擎可完全脱离宿主运行，导出链路完整可用。** M0 编排器采用**进程内直调引擎模块**（`import { runExportOnly } from executas/ppt-engine/src/export-only/index.js`），不需要 HTTP 服务化。

## 关键发现

1. `src/http/server.ts` 只有模板渲染接口（healthz/template-groups/render-slide），**无导出与工作区接口**——它是模板预览服务，不是完整后端。HTTP 化留待 M1。
2. 完整导出能力在 `src/export-only/index.ts` 的 `runExportOnly()`：输入 `source_root + deck_html_file + expected_slide_count + output_dir`，返回状态/警告/耗时。deck.html 格式样例见 `evals/export/cases/`。
3. 浏览器：`CHROME_PATH` 环境变量可指定 Chrome 可执行文件（本机 `C:\Program Files\Google\Chrome\Application\chrome.exe` 可用）。无此配置时引擎只找 LOCALAPPDATA 候选路径。
4. 构建产物依赖：`src/pptx-export/vendor/dom-to-pptx/dom-to-pptx.bundle.js` 是构建期生成物，已从原仓 dist 拷贝补齐（**不入 git**）。正式构建链为 `scripts/build-dom-to-pptx-runtime.mjs`（从 `third_party/dom-to-pptx` 构建）。
