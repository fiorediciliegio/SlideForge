# 模板推荐分支合并验证

日期：2026-09-28。

## 合并范围与历史

- 目标基线：`anna-ppt`，`a9447ec2c62eef287c28654cfaaeb52d3ab32347`。
- 来源：`feat/attachment-preflight-migration`，`a08c2bd5249b6d555068a2ba587defa1d04fc3ed`。
- 采用真实双父合并提交，第一父提交为目标基线，第二父提交为来源分支；集成验证后将 `anna-ppt` 快进到该提交，不压缩或挑选提交。
- 代码、资源、测试和文档变更均限于 `apps/ppt-app`。

## 最终取舍

接入十套新模板、语义配色、模板意图分析与本地推荐评分、低信号人工选择，以及模板推荐批量测试。保留目标分支的项目指导文档、四语言拆包、普通调用网关、字体 HTTPS 策略和完整批次返回契约。

模板确认使用 `template_snapshot`；自动推荐只使用内置模板。首页实时配色预览按交互触发加载并保留 iframe。手动及历史无模板草稿也不能绕过低信号人工选择。批量推荐保留取消检查与工作区调用日志。相关领域约定见 ADR-0073。

## 已通过检查

- App 与引擎 `npm run check`。
- 引擎构建，随后 App 构建；仅有构建体积提示。
- 四语言校验：每种语言 1475 个词条，键、占位符和语言分支检查一致。
- 模板校验：98 套模板、861 张 WebP。226 条已有模板资源警告与基线一致；基线为 88 套模板、811 张 WebP。
- 真实插件 `describe`：引擎 6.0.9，仍只公开两个普通调用网关及两个异步入口。
- 引擎定向测试 23 项全部通过：需求持久化与门槛、批量推荐结果、批量传输、工具清单、统一传输及分块协议。
- 前端本次相关用例通过：推荐、配色、需求确认、批量附件／恢复／复用、取消推荐、普通传输和按需 iframe 加载。
- 快照触发竞争用例单独复测通过。导出镜像的 6 项用例通过；测试退出前等待后台快照队列，避免临时目录清理与异步写入竞争，未修改生产快照逻辑。
- Git 差异空白检查通过，冲突标记已清除。

| App 全量单测 | 929 项：908 通过、21 失败 | 954 项：934 通过、20 失败 |
| 引擎全量单测 | 387 项：355 通过、28 失败、2 取消、2 跳过 | 388 项：359 通过、27 失败、0 取消、2 跳过 |

App 剩余 20 个失败名称均出现在原分支的失败集合中，没有新增失败；同事对工具栏测试的适配消除了一项旧失败。剩余问题涉及旧的人工编辑 DOM 断言、字体测试、生成进度页、大纲提示词、图片附件说明及模型默认值断言。

引擎旧失败主要涉及已退出主流程的 Authoring Kit／TSX 渲染测试、旧截图和页面更新契约、Windows 专属进程、PDF OCR 断言及外部导出调用超时。全量运行还有并发和浏览器环境波动，因此不能把功能定向用例通过描述为全量测试通过。最后一轮引擎失败名称全部属于基线失败集合，没有新增失败。两处快照相关复测与测试清理修正后的全量运行均通过；原分支中另外两处取消及一次状态失败在本轮未出现，属于运行差异，不宣称已修复。

严格校验错误定位在未改动的 `scripts/upload-binary.mjs`：合法参数 `tool-id` 被检查器认为是 `tool-ids` 的近似拼写。基线对照复现同一错误，本次没有为绕过检查而更改发布脚本。
