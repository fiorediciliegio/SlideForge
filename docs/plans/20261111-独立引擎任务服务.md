# 独立引擎任务服务实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans，Native 顺序执行。

状态: done · 最后验证: 2026-11-11

**Goal:** 所有在线检查、截图、PDF/PPTX 通过独立引擎作业执行，业务 Node 不依赖引擎目录。
**Architecture:** Go 持久队列、私有 artifact 和交付回执；引擎按租约拉取固定快照；Node 只提交、查询、使用结果；Python 保持单总控，每实例最多 5 项目并发。
**Tech Stack:** Go / PostgreSQL / 现有 S3；TypeScript / Node / Puppeteer；Python 标准库。无新基础设施依赖。
**Spec:** `.scratch/engine-job-service/PRD.md`

## Global Constraints

- 基线 d725c2b；本期 A：引擎独立和多实例，不做业务 Node 项目存储的跨副本接管。
- 输入无绝对路径和任意下载 URL；私有 artifact 不出现在客户导出列表。
- 开发引擎并发 1，可配置；运行租约 30 秒、心跳 10 秒；失联最多重新执行一次，错误/超时/取消不重试。
- 相同 owner/source/kind/params 复用活动及成功任务；旧 operation_id 保留原终态。
- 公平轮转 owner；短任务与导出按 2:1 派发，非抢占。最多 100 个排队任务、每 owner 20 个，满时明确拒绝。
- Agent 排队时间不计有效执行；同一 Agent 并行活动按墙钟一次计费。
- 真实模型不参与批量压测；固定 6/20 页 HTML + 真 Chrome + 假模型。

## Review Focus

- 旧租约完成不能发布新结果；取消只释放本任务浏览器资源。
- 输入里本机路径/外链资源不能绕过隔离，输入上传后源文件改变不影响任务。
- 导出扣点成功但发布/响应失败，重试复用同一扣点 ID。
- 同一版本多人/多窗口请求共享任务，失败后显式新操作才能再执行。
- 部署实例重启不能把健康 worker 的任务中断；未就绪服务明确报错而非本地执行。
