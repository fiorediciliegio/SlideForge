# P1 三服务骨架实施计划

- 状态: active
- 日期: 2026-11-01
- 最后验证: 2026-11-01
- 依据: `docs/product-tech-charter.md`，不新增或翻案架构决策

## 目标

在 P0 现役链路契约与工作区收敛后，开始总纲既定的三服务架构：Go 骨架层、Node 引擎层、Python 大脑层。跨服务协议先落入根目录 `contracts/`，实现不得绕过契约另建客户端专用业务接口。

## 本阶段边界

- 新建 Go 网关，提供统一入口、配置校验、请求 ID、结构化日志、超时、优雅退出和 Node 上游代理。
- Node 现役 Capability API 暂时继续承接鉴权、计费、任务和业务存储，避免迁移期双事实源。
- 不在本阶段引入 PostgreSQL、Redis、Python 服务或第二个鉴权实现。
- 不改变 MCP 工具、生成算法、HTML 方言、PPTX 导出和计费规则。

## 里程碑

### P1-A 契约与 Go 网关骨架（done · 2026-11-01）

- `contracts/openapi/gateway.yaml`：健康检查、创建、查询、导出和错误模型。
- `services/gateway/`：Go module、配置、HTTP 基础设施、反向代理和单元测试。
- 网关 `/healthz` 描述自身；`/readyz` 检查 Node 引擎上游。
- 其余现役路径在过渡期透明代理到 Node，保留 API key、请求体、查询参数与流式响应。

### P1-B 认证与计费归属迁移（done · 2026-11-01）

- 先定义认证和计费 API，再由 Go 独占用户、key 与点数事实源。
- Node 改为验证网关身份或接收已认证主体，不再独立读取用户存储。
- 数据迁移与回滚独立实施，不能双写后长期不校验。

### P1-C1 异步 job、SSE 与取消（done · 2026-11-01）

- Go 独占任务记录，Node 通过内部 API 创建、读取、更新、列表和删除。
- 公共任务查询由 Go 直接处理，`GET /decks/{deck_id}/events` 提供 SSE 快照与更新。
- `POST /decks/{deck_id}/cancel` 记录协作式取消，后续完成事件不能覆盖取消状态。
- 保持历史 `deck_id` 与 `runDir` 兼容。

### P1-C2a 任务 webhook（done · 2026-11-01）

- `POST /decks/{deck_id}/webhooks` 按作品注册 HTTPS 回调，loopback HTTP 仅用于本地开发。
- HMAC-SHA256 签名、有界队列、最多 3 次投递与 JSONL 审计已验证；secret 不进入公共 DTO 和日志。

### P1-C2b 文件协议迁移（done · 2026-11-01）

- `contracts/openapi/files.yaml` 与 Go 文件服务覆盖内部发布、作品文件列表和按 API key 隔离的公共下载。
- Node 导出后经 `SLIDEFORGE_FILE_API_URL` 发布文件，回执与 Web／MCP 均携带 `file_id`、`download_url`。
- 远程幂等回执在本地文件清理后仍可复用；缺少文件归属时拒绝发布。

### P1-D1 Node 独立引擎 API（done · 2026-11-01）

- `contracts/openapi/engine.yaml` 与 `src/http/engineServer.ts` 提供页面校验、预览和 PPTX／PDF 导出。
- `npm run serve:engine` 默认监听 3211；内部接口使用 `GATEWAY_INTERNAL_TOKEN`。
- 工作区限制在 `SLIDEFORGE_DECKS_ROOT` 直接子目录，导出路径限制在对应 Deck 内；真实 Chrome 与 PPTX 集成测试已通过。

### P1-D2a Python 大脑层基础服务（done · 2026-11-01）

- `contracts/openapi/brain.yaml` 与 `services/brain` 提供配置、内部鉴权、健康检查、Prompt 编排和文档分块。
- 文档结果包含稳定 SHA-256 与字符位置；HTTP 和单元测试通过，无第三方运行时依赖。

### P1-D2b 大纲与文档职责迁移（done · 2026-11-01）

- Python 直接调用 OpenAI 兼容模型并校验大纲结构、页数，token usage 回到原计费上下文。
- 大纲与逐页 Prompt 均由 Python 编排；Node 通过 Brain 客户端远程调用，未配置时保留本地回退。
- DOCX／PDF／TXT 提取迁移到 Python；Node 在 `SLIDEFORGE_BRAIN_API_URL` 启用后使用远程大纲和附件能力，不静默回退。

### P1-D2c 图像分析与 Evals（done · 2026-11-01）

- `POST /internal/brain/image-drift` 提供尺寸归一化、平均通道差、RMS、变化像素比例与差异框。
- `POST /internal/brain/evals/run` 支持大纲、文档和图像声明式夹具及逐例结果；Node 客户端类型已同步。
- 图像输入增加 4000 万像素上限，Eval case id 强制唯一；函数与真实 HTTP 测试覆盖零漂移、缩放、阈值、异常与逐例统计。
- 原有 HTML 文本／样式 diff 保留，不与像素级分析混用。

### P1-E 三服务入口收敛（done · 2026-11-01）

- `npm run dev` 统一启动四个受控进程，客户端只访问 Go 网关 8080；`dev:legacy` 保留单 Node 兼容入口。
- `/readyz` 分别检查 capability、engine、brain；生产提供独立 systemd 单元与 Go 二进制构建。

### P1-F 三服务联合验收（done · 2026-11-01）

- 使用项目内便携 Go 1.27.3 工具链完成 `go test ./...` 与 `go vet ./...`，未修改系统 Go 环境。
- 真实 Go／Node 远程任务、凭证、SSE 与取消通过；统一 `dev` 入口在全部服务就绪后通过 Go 提供 Web 应用。
- `threeServiceSmoke` 一次跑通 Go 鉴权与文件下载、Node 导出与预览、Python Prompt 与文档提取；全量 36 项 Node 测试无跳过。
