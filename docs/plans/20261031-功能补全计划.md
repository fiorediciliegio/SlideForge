# 功能补全开发计划（2026-10-31）

- 状态: **done · 全部实现并验证**

## F1 联网研究（带资料来源生成）

- 目标：生成时可选择联网检索，把检索结果与来源 URL 注入为事实来源，页面标注来源。
- 方案：DuckDuckGo HTML 检索（免 key）→ 结果解析 → 抓取正文 → 与 brief 合并注入；prompt 强制来源归属。
- 接口：`POST /research {query}` 预览检索结果；`POST /decks {research: true}` 自动检索。
- 验收：生成内容包含检索到的事实与来源 URL。

## F2 布局级手动编辑（拖拽/缩放）

- 目标：手动编辑器里可选中元素并拖动位置、调整大小，保存回写。
- 方案：iframe 内注入选择框/手柄（绝对定位元素），拖拽更新 style.left/top/width/height，经 `updatePageHtml` 保存。
- 验收：拖动文本块后保存，预览与导出同步变化。

## F3 多模型故障切换

- 目标：主模型失败（429/5xx/超时）自动切换备用 provider。
- 方案：provider 列表（env 配置主备）+ llmClient 按序尝试，记录实际使用 provider。
- 验收：主 provider 不可用时自动走备用并返回结果。

## F4 设计档案与母版优化（原系统深度功能）

- F4a 设计档案提取：从品牌 pptx 参考页生成结构化五节档案（配色/字体/版式/组件/固定资产）；
- F4b 母版对话优化：对话修改品牌视觉规范 + 偏离度对比（复用 drift）。
- 验收：上传 pptx 得到档案 JSON，对话调整后生成风格随之变化且可审计。

## 顺序与验收

F1 → F2 → F3 → F4a → F4b。每项完成后跑对应验证再提交，最后统一更新 current-state 与文档索引。
