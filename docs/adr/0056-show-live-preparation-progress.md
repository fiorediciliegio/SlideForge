# 在等待页面展示可展开的生成过程

演示需求、大纲和研究的等待过程使用统一的步骤组件：收起时展示状态和结果摘要，展开后查看字段、实时原文、网页来源、读取正文或图片。沿用现有紫色视觉变量、中英文文案及性能交互标识。

演示需求保留附件处理、语言、需求候选、模板（包含自动选择的颜色）、研究推荐与保存结果。当前直接 LLM 接口仅支持 `complete`，结果返回后立即展示，不模拟逐字输出。大纲沿用 Agent Session，透传流式内容；标题与总页数、各 20 页正文段、纠正和新会话尝试分别保存在独立可折叠原文卡片中，后续输出不覆盖前轮；图片分配和保存各有独立状态。正式需求确认、大纲校验与保存条件保持不变，进入确认页后不展示此前的等待过程。

Web 与图片研究继续遵守 ADR-0055 的并发及独立开关。外层步骤保留状态、摘要、耗时和折叠；内层使用无卡片边框的紧凑操作行，搜索词和每个抓取网页各自可展开，分别显示搜索结果与正文。候选图片列表只显示缩略图，点击后在大图详情中展示标题、来源、选择状态、说明和不可用原因；模型选中与导入后可用仍是不同状态。报告的 `finish` 动作头只属于协议，实时报告视图展示其后的正文。报告默认在操作列表下方直接展示，以不执行 HTML 的受限 Markdown 排版，并保留原文入口。

研究界面不展示各轮模型原文、查询报错、抓取技术错误或独立缺口列表。可继续生成的 `warning` 在研究步骤中投影为正常的“已完成”和对勾，不修改检查点中的实际状态和资料边界。工具访问的非阻断警告只进入 AI 交互日志，不作为活动事件发送给界面；真正阻断流程的错误仍保留失败反馈。

实时文本和临时图片预览地址仅属于当前运行的内存状态，不写入检查点或 Page Progress。检查点继续持有原始搜索、抓取和图片处理结果；所有 Page Progress 写入剔除视图专用的大内容。图片可以先展示搜索返回的地址，APS 获取成功后优先使用当前有效地址，不保存短期 `get_url`。失败图片保留来源与状态。

文本更新合并到约 80 毫秒一批，尾部更新也必须刷新。用户折叠或向上阅读后不抢展开状态与滚动位置，提供回到最新内容的入口。失败保留已完成步骤及当前已收到内容；运行标识防止过期回调污染下一次生成。只播报阶段变化，不逐字播报长文本。等待时间不转换成虚构的完成百分比。

附件处理只在统一步骤列表展示；文件名与状态分列，长文件名可换行，OCR 页码进度与摘要批次说明保留在该步骤中。已完成且无额外输出的步骤不展示等待提示，准备资料和配图步骤提供结果摘要。

大纲改写复用生成过程视图，单独区分改写与普通保存状态，依次展示资料准备、流式改写、配图调整、校验保存。改写期间保留旧草稿与修改意见，完整结果通过校验并保存后才替换草稿；失败回到审阅页并保留过程与重试入口。重试保留本次任务此前各轮原文；生成失败后的显式重试，以及相同输入和修改意见的改写重试，沿用原有步骤开始时间。修改输入重新发起任务时才清空过程并重新计时。离开页面继续沿用准备阶段的取消保护。展开的大纲卡片不再重复展示“页面完整大纲”及同名标题，保留页面标题字段与前后新增操作。

原文卡片统一展示标题或页码范围及状态，不展示容易与生成轮次混淆的会话副标题；会话和纠正编号仅在内部过程记录中保留。当前轮默认展开，结束后默认收起；用户手动展开或收起后保持选择，折叠外层步骤也不清除卡片选择。完整响应返回时补齐本轮原文，包括没有流式事件的响应；失败保留已经收到的部分文本。各轮记录仅供当前任务查看，不参与跨会话的大纲组装或校验，不跨刷新持久化。
