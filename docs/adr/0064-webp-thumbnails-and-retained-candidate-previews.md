# ADR-0064：每页 WebP 缩略图与候选 HTML 会话保留

> 普通 `invoke` 的固定上传及旧传输预算已由 [ADR-0071](0071-unified-ordinary-invoke-transport.md) 替代；本篇的业务语义、资源存储及异步协议约定仍有效。

- 状态：已采纳
- 日期：2026-09-20
- 调整：ADR-0063 的列表展示和离屏卸载约定；结果页 HTML 大图沿用 ADR-0057。

## 背景

封面、缩略条和网格改用完整 HTML 后，首次显示需要解析样式及加载图片、字体；候选卡片离屏就卸载 iframe，滚回时即使命中文本缓存也会重新渲染。

## 决策

1. 每个正式页面保留当前版本的小尺寸 WebP，长边不超过 640 像素、保持页面比例。第一页的同一张图片用于作品封面；网格、缩略条、生成进度缩略图、人工编辑缩略图和批量测试页面复用逐页图片。主预览及放映继续使用 HTML。
2. 图片在 `output/page-thumbnails/<页面标识摘要>/` 中维护，按 HTML 和本地素材内容指纹校验。普通逐页生成提前准备；旧作品、缓存丢失、人工保存及候选采用后的新版本在首次展示时补齐。单页请求串行协调，成功发布新图后清理该页旧图，不保留缩略图历史。图片不是权威内容，不进入云端作品快照，也不是页面生成成功的必要条件。
3. 通过 `PptBackend.getWorkspacePageThumbnail` 获取图片，省略页面标识时读取当前第一页，人工修订优先。完整响应在 48 KiB 内时直接返回 WebP 数据地址，否则通过 Host Upload 返回可复用引用。前端对下载地址按有效期缓存，图片加载失败时自动刷新引用一次；已显示图片不会因缓存到期自动卸载。首次准备并发上限为四。
4. 候选卡片继续显示静态 HTML，接近视口时首次按需准备，并发上限为四。已启动的预览不因离屏取消或卸载；成功后的 iframe 保留到退出候选页或切换批次。状态轮询不重建同版本内容，内容版本变化或显式刷新才允许重建。
5. 已打开的候选放大预览关闭后保留，重新打开同候选复用其 iframe，退出候选页统一释放。HTML 文本缓存的过期和淘汰不清理已加载网页实例。
6. 结果页大图维持现有实现：保留已加载页，切页仅隐藏；进入同一作品的编辑、候选、导出等操作时保留，返回我的作品或切换作品时释放。AI 会话截图仍只作临时附件，上传后删除，不恢复长期整页 PNG。
7. 旧图片迁移清理仅处理 ADR-0063 已知的历史目录，不删除新的 `page-thumbnails`。正文图片、字体和模板预览资源不受影响。
8. 美化／批量重新生成的候选采用、指定页面优化、人工编辑共用前端结果发布入口；生成事务、候选采用和人工保存继续使用各自的业务协议。发布时按 `page_id` 关联大纲标题，对照页面进度、正文哈希和已知预览指纹，只替换变化页的预览版本。轻量元数据的更新时间与严格元数据的内容指纹不是同一类版本，不能仅因切换读取方式就刷新所有页面。人工保存同时同步回执中的正文哈希与预览版本。
9. 变化页集合与返回页标识分开：候选采用、指定优化及其恢复返回操作目标；人工编辑逐页保存只累计更新，退出时返回编辑器最后查看的页面，保存顺序不决定返回位置。页序变化时按标识重新定位；目标不存在时限制在有效页范围。必要的整稿预览重建保留已显示内容，失败可继续查看已有预览。作品身份、内容版本和发布序号共同阻止迟到请求覆盖新结果。
10. 结果页收到轻量元数据后，仍将完整页面目录交给预览会话；空 `html_path` 或 `preview_unavailable` 不关闭整稿预取。会话沿用十路 HTML 获取、四路网页准备的上限，逐页准备缺失预览，单页失败不阻塞其余页面。目录更新继续按逐页版本合并：未变化的已加载页面复用，变化页获取新版本，尚未完成的后台页面继续原请求。预取不改变返回页选择，也不清空整稿缓存。

## 验证

覆盖 WebP 格式、尺寸、缓存复用、素材变化失效、截图失败与版本竞争、当前版本替换、旧图迁移保留新缓存、传输预算及前端并发和过期重试。使用 DOM 挂载测试确认候选滚出再滚回、状态刷新后仍是同一 iframe，退出后释放。结果页既有会话测试保持不变。实际浏览器中的字体、画面清晰度和首屏耗时仍需运行中的 App 验收。

结果发布回归覆盖候选采用、指定优化与人工编辑的实际回调，以及真实结果页组件的图片／iframe 实例复用；验证第九页操作、第十一页退出、多页连续保存、页序变化、轻量／严格元数据切换、重建失败和跨作品／跨版本迟到响应。

轻量元数据预取回归从空缓存挂载真实结果页组件，验证不切页也会按并发上限获取全稿、单页失败释放名额、第四页选中前已准备，以及后台获取期间更新第九页只刷新本页、保留其他网页实例并丢弃旧版迟到响应。

## 2026-10-01：结果页整稿缩略图后台预取

- 结果页拿到完整页面目录后，主动逐页准备并获取所有当前版本 WebP，离屏图片也以 `loading="eager"` 挂载并下载、解码。任务在图片解码完成或失败后释放名额，不能仅缓存地址或在后端生成文件后就视为完成。
- 缩略栏会话同时最多处理四张图片，纯后台最多三张，为当前页及接近可视区域的页面保留名额。顺序为当前页、接近可视区域的页面、按距离排列的邻页及剩余页面；同距离先下一页。滚动及切页会重排尚未开始的工作，已启动请求继续复用。缓存请求队列在收集一批组件请求后按最新优先级启动，不能被 DOM 排列顺序覆盖。
- 继续通过 `PptBackend` 和已有后端前台／后台准备协议读取 WebP，共用逐页版本缓存及请求去重。缩略图调度独立于 HTML 整稿预取，不改变后端准备队列的串行及优先级契约。相同页面版本的元数据刷新、切页及收起缩略栏不重新下载或卸载已显示图片；版本变化只重新准备变化页。
- 图片下载及解码等待有上限，图片失败只刷新一次，单页最终失败不阻塞其他页面。首次后台失败显示现有多语言失败状态，不为从未可见的离屏页面批量创建备用 iframe；进入可视区域后仍可按现有策略展示 HTML 备用预览。旧版本、旧作品及已卸载组件的迟到事件不能更新当前画面。
- 返回作品列表、切换作品或卸载缩略栏会释放本会话，不再调度剩余页面。同一作品进入编辑、候选、导出等页面时，仍沿用隐藏挂载的结果页保留规则。作品列表封面、网格及其他缩略图入口继续按可视区域加载。

DOM 回归覆盖空缓存和轻量元数据下无需滚动即可预取整稿、下载及解码并发、预留名额、滚动与跳页优先级、单页失败、图片有界重试、逐页版本更新、跨作品晚到响应和退出后停止调度；原有 HTML 预取、候选采用、优化、人工保存和生成页预览连续性回归继续通过。模拟测试不代替真实浏览器图片绘制及 APS 网络耗时验收。
