# ADR-0069：大纲与单页候选的按页关键词搜图

状态：已采纳；当前实现与 [ADR-0077](0077-image-candidates-and-deferred-descriptions.md) 一致。

入口、选择草稿及搜索窗口交互已由 [ADR-0078](0078-unified-page-image-manager.md) 更新；搜图任务和素材存储规则继续沿用本文。

## 背景

用户需要在大纲详情和单页批量重新生成中补充图片，使用当前未保存的选图输入，且不提前修改正式页面。按页入口现已采用一次关键词搜索，不再执行旧版多轮图片研究会话。

## 决策

- 两处共用“为本页搜索图片”弹窗，打开即显示关键词输入和开始按钮，不等待历史任务或素材库读取。每次开始创建新任务，一次最多获取 20 个结果，以最多 10 路并发调用 `image_fetch`（原图获取）校验受支持图片，按完整 SHA-256 去重。
- 成功获取结果保存稳定 APS 引用、内容哈希、格式、字节数和来源。同内容结果合并 APS 路径及来源；刷新预览地址失败不丢候选，不回退旧地址。临时地址在任务保存时清空，预览及采用时重新刷新。
- 搜索不会把全部原图复制到作品，也不调用描述模型。勾选添加后通过共用图片库下载、核验原图并发布正式素材；成功保存即返回空描述素材。同内容已有上传或搜索素材复用原标识，部分文件失败隔离并支持重试。
- 独立任务保存在 `research/page-image-search/`，保留工作区租约互斥及目标、搜索预算不可变边界，不覆盖首次研究检查点。已确认页按稳定 `page_id` 关联，未确认草稿按内容指纹关联。用户界面不提供继续旧任务或历史任务切换。
- 搜索及取消收尾期间禁止关闭弹窗（包括 Esc），取消停止后续抓取并保留已成功获取结果。文件添加期间同样禁止关闭，全部成功后关闭；部分或全部失败时保留结果供重试。当前编辑期间重新打开可查看本次结果。
- 搜索结果添加与已有素材选择使用相同的确认按钮加载状态：转圈图标及共用四语“正在保存图片”文案。保存期间的进度反馈集中在按钮中，避免额外插入处理步骤或自动滚动；关键词搜索仍保留自身的搜索进度，文件失败沿用可重试错误提示。
- 添加素材与页面修改分开：大纲详情只更新本地编辑，仍需显式保存；单页批量重新生成只更新候选输入，采用候选前不改正式大纲及页面。已获取候选可在共用素材选择器继续采用。
- HTML 生成前统一为实际选用且缺描述的图片补描述，失败继续，取消停止；该步骤不放回搜索添加入口。四语说明与文件失败状态沿用现有国际化语言包。

## 验证

定向测试覆盖搜索和抓取并发上限、内容去重与 APS 引用合并、地址失效保留候选、添加不调用模型、空描述立即可用、按哈希复用、部分文件失败重试、取消保留已获取结果、租约和不可变快照，以及弹窗忙碌与显式保存边界。真实宿主 APS 保留契约与浏览器交互需另行联调。
