# ADR-0080：Python Brain 单总控 Agent Harness

- 状态: accepted
- 日期: 2026-11-10
- 决策人: 用户确认产品与技术方案
- Supersedes: ADR-0075 中不提供页面历史回退的产品条款；ADR-0072 方言契约中失败候选重试后接受的条款，仅适用于新 Harness 路径。

## 背景

现有固定生成流程缺少工具决策、持久上下文、质量闭环和中断续跑。用户已确认[产品设计](../../.scratch/python-brain-harness/PRD.md)及[代码修改方案](../plans/20261110-Python-Brain-Harness改造方案.md)。

## 决策

- Python 单总控负责规划、工具选择、观察和返工。Node Capability 管理生成工具、HTML 与渲染导出，Go 独占执行状态、预算、回执和当前修订引用。
- 先写不可变 artifact，再通过 Go 条件事务提交引用与回执。稳定 page_id 独立于页序，每个工作区 slides 为权威正文，历史版本归档，回退创建新版本。
- 默认直接生成，可选择先确认可编辑大纲。固定/范围/自动页数总计2–20页，确认结构不得由模型自行变更。
- 每次执行默认600秒有效时间、模型成本估算2元，等待用户不计时。所有嵌套模型调用共享预算；未知结果不自动重新调用。
- 非法或溢出候选保留诊断但不替换当前有效页面。分开记录版面、内容与视觉检查，按有效指纹复用。
- 首先交付 Web；旧客户端仍使用已有契约，所有已迁移作品写入必须进入版本链。默认交付预览，显式授权后导出收费。

## 备选方案

固定管道无法根据观察自主选择返工；首版多 Agent 增加交接、调用和一致性开销，用户选择单总控。沿用现有标准库服务及存储，不引入框架、Redis或Celery。

## 影响

新增任务/预算契约、项目快照、模型工具消息、Web大纲及恢复交互。Go JSON和PostgreSQL执行相同条件更新；未知供应商调用仍可能收费，记录不确定性。模型能力与性能在实施验收时实测。
