# 大纲前收集图片，大纲后分配并由用户确认

用户需要将搜索图片及上传附件中的配图接入主生成流程。本决策取代 ADR-0054 的图片封存范围，以及 ADR-0043 中“大纲确认后搜索图片、页面自行从整套目录选图”的约定。

确认演示需求后，Web 研究与图片搜索使用独立会话并发执行。两项仍遵守用户各自确认的开关。协调器只初始化一次共享检查点，各分支只更新自己的记录，等待两项都结束才最终确认研究状态；重试复用已完成的分支和保存的结果。图片搜索的业务输入为原始需求和已确认演示需求，不接收大纲或 Web 总结；恢复时可接收既有图片和搜索历史。搜索结果标题随候选传给图片会话，并保存在正式素材目录中。图片选择理由说明与演示需求的关联，不指定页面。

上传图片在附件预处理流程中通过图片会话生成描述与用途判断。只有 `use_in_ppt: true` 的有效附件进入上传素材目录，关闭外部图片搜索不会禁用上传图片。图片转写及摘要可随其他附件资料进入需求和大纲；图片及标题本身不自动构成事实证据。原始附件与可用上传素材继续保留原有存储归属。

大纲文字生成完成后，独立图片分配会话读取原始需求、演示需求、逐页大纲和全部可用图片元数据，不附加图片字节。上传图片优先；图片必须直接支持页面的信息或视觉表达，允许一页多图或无图，不为了装饰强行配图。自动分配默认避免同一内容图片跨页重复，按内容哈希识别不同来源的重复图片。用户可手动跨页复用，改写时允许保留已有复用次数，不自动增加复用。

每个大纲项增加可选的 `selected_image_ids: string[]`。旧大纲缺省视为无图；大纲草稿、确认、重新打开及页面重排保留该字段。复制页面不复制配图，以免重复使用。人工移除只解除分配，不删除素材；AI 改写后重新执行分配，传入改写前的大纲与用户配图，要求尽量保留对应关系。分配协议校验完整页集合、素材存在性和重复使用，失败沿用会话修复与重试，不将非法分配保存为成功结果。后端保存、确认及单页候选创建和采用校验素材引用及页内内容去重，允许跨页复用。

大纲卡片展示图片数量，展开后可查看缩略图并移除图片。添加弹窗展示已保存素材和成功获取的完整 APS 搜索候选，包括 AI 未推荐和未分析的候选；卡片不展示推荐或分析标签。勾选立即更新弹窗草稿，点击“完成”时统一下载所选远程候选，全部成功后应用到外层编辑。部分失败保留选择，仅重试未成功图片；直接关闭不应用草稿。支持来源筛选及标题、描述检索，标注其他已选页面的页码但不禁用，超过三页时折叠显示并支持展开。修改沿用大纲的显式保存和确认机制。正式素材缩略图由 `PptBackend` 按素材标识读取，引擎校验当前有效目录和真实路径归属，返回有界 WebP 预览；点击图片按需请求更高分辨率的预览，并支持关闭后回到选择器；前端不读取本地文件系统。

页面创作在“页面大纲”后追加“本页可用图片”，只解析本页已选素材，包含图片描述、标题和当前工作区绝对路径。封面、普通页、精修和单页候选生成复用这一输入边界。单页批量重新生成复用大纲的图片选择器，所有候选共享本次编辑后的图片输入，采用前不修改正式大纲。没有选图的页面不获得整套图片目录；生成阶段不再次触发外部图片搜索。已有影子工作区及提交机制继续负责素材路径转换。

本页已选图片在 HTML 创作提示词中明确作为用户指定配图，必须全部清晰展示，不是可由页面模型继续筛选的候选素材。模型可以按图片数量调整布局，但不得遗漏、隐藏或替换；模板参考和默认排版建议不能覆盖此要求。封面、普通页、精修和批量重新生成共用这一规则，不增加生成结果的漏图检查。

搜索添加与手动上传保存成功后即可使用，不在添加时调用描述模型。空描述是正常素材状态；HTML 生成前只对实际选用且缺描述的图片按每批最多 6 张补描述，最终失败继续生成，取消必须停止。完整候选、人工采用及描述准备的当前约定见 [ADR-0077](0077-image-candidates-and-deferred-descriptions.md)。

新入库的页面配图统一按内容哈希生成 `image-<SHA-256 前 16 位>.<扩展名>`，覆盖首次搜索、按页补图和用户上传。命名由引擎共用逻辑负责；完整哈希及素材标识保持独立，短文件名冲突时拒绝覆盖不同内容。历史素材和已有 HTML 保留原路径，不自动迁移。

验证覆盖：并发研究及开关组合、恢复不重复搜索、附件用途分类、标题保存、分配协议、跨来源内容去重、大纲保存/确认/重开、图片预览访问边界和逐页 HTML 提示词。
