# 单页批量重新生成使用独立候选目录

演示文稿生成完成后，用户可以对当前页生成 1～10 个候选方案。入口从演示文稿页进入一个独立的配置页，而不是弹窗；配置页允许修改页面标题、核心信息、大纲、本页创作要求和配图；本页创作要求默认回显已有值，可修改或清空，所有候选共用，采用时随该页大纲回写；配图复用大纲选择器，支持跨页复用和大图预览。底部操作栏随内容滚动，返回按钮与演示文稿页保持一致，不提供历史批次入口；每个方案使用独立的 Agent Session（生成会话），遵循现有 HTML 页面提示词、视觉母版和单一模板参考规则。封面不读取视觉母版。会话按用户指定数量并发启动；静态化和截图沿用引擎现有浏览器渲染队列。

这一操作属于单页候选生成，不是 Deck Generation（整套生成）或 Page Refinement（单页优化）。它不启动影子工作区，不修改正式页面进度，不返回需求或大纲确认阶段，也不增加停止、回退或撤销采用功能。用户确认采用前，原页及原导出仍是正式结果。

## 存储与边界

- 批次存放在当前 Workspace 的 `.page-regenerations/<batch-id>/batch.json`。
- 每个候选拥有独立 `candidates/<candidate-id>/`，包含 `slides/<page-id>.html`、仅用于保持原始页序和总页数的最小渲染索引，以及静态 HTML 和 PNG。没有其他页面源码、共享资料或完整工作区副本。
- 批次记录编辑后的单页大纲、模板参考、创建时正式内容指纹和候选状态；候选状态为生成中、渲染中、完成或失败。
- 前端通过 `PptBackend.pageRegeneration` 调用后端。HTML 使用 Host Upload（文件传输）提交，截图通过上传引用返回，不以内联图片字节传输。
- 候选的生成、上传或渲染失败只影响自身。界面逐个显示实际截图，全部候选结束后允许从成功方案中选择；预览传输失败可以刷新，不抹掉已渲染的结果。
- 生成中的批次由前端操作标识续约两分钟的执行租期。应用退出或持续失联后，查询将过期且尚未提交的候选标记为中断失败，保留已完成方案；引擎仍在执行的渲染独立继续。不会自动续跑生成会话。

## 采用

用户选择方案后必须确认替换提示，其中说明已有人工编辑会被替换、该页正式大纲会同步更新，其他候选会被清理。

采用操作保留 `page_id`、页面类型、页序和大纲已确认状态，只替换目标大纲项与 HTML 页面源。选中方案的静态 HTML、PNG 写入正式输出目录，更新 Page Progress（页面进度），解除该页人工修订的当前版本身份，并根据全部当前静态页面重新组合 Deck HTML（整份演示 HTML）。这一组合不执行其他页面的 Agent 或重新截图。旧 PDF/PPTX 的正式导出记录和 PPTX 作业状态失效，下次导出使用新内容。

采用前检查演示文稿的版本指纹和选中候选的源码、静态 HTML、PNG 指纹；生成期间其他操作改变了正式内容，或候选文件与截图不再一致时，拒绝覆盖。重复采用同一个结果返回已有成功结果，不能再从已采用批次选择另一个方案。

发布使用只涵盖受影响文件的短期写入日志，准备完成后连续替换文件。正常失败或进程中断后恢复未完整发布的文件，避免大纲和页面源属于不同版本；该日志不构成影子工作区、用户历史版本或回退产品流程。发布成功后清理候选目录，保留最小采用记录以处理重复请求，并触发既有工作区快照同步。诊断日志继续属于原 Workspace。

这项决策为单页候选采用增加一项明确例外：它允许保持大纲确认状态而更新对应页面意图；普通大纲编辑仍遵守原有保存与重新确认规则，既有单页优化仍不回写大纲。
