# 合并图片附件能力，暂不接入主生成流程

图片封存范围已由 [ADR-0055](0055-assign-images-during-outline-review.md) 取代；下文保留当时的合并决策。

将 `feat/attachment-preflight-migration` 合并到 `slideforge-ppt`，保留双方提交历史，以 `slideforge-ppt` 为第一父提交。此次保留图片上传、首次多文件上传共用工作区、图片摘要客户端及引擎素材能力，但不启用图片摘要对演示需求、研究、大纲或页面的影响。

`IMAGE_ATTACHMENT_BRIEFS_ENABLED` 暂为 `false`。交互和批量入口跳过图片摘要生成；提示词边界过滤旧工作区已持久化的图片摘要。文档、表格及 PDF 的处理、OCR 续跑、摘要和纯文本大纲输入继续使用既有流程。大纲沿用当前协议和会话生成；页面、封面、精修和单页候选生成沿用 `slideforge-ppt` 的提示词及调用方式，不增加图片目录输入。后续图片如何进入主流程由单独的开发决定。

底层图片能力保留供后续接入：无文字图片允许空转写，不要求凑足三条事实；模型调用复用统一会话修复和重试。图片素材写入在工作区上传队列中串行执行。删除或忽略附件后，返回的素材目录按当前有效附件过滤；图片改判为不用作配图时移除其目录条目，但保留已有页面可能引用的图片文件。

作品快照同时保存 `uploaded-sources/asset/` 的素材和目录，原始附件不重复放入快照。移除附件只操作当前作品，不通过扫描其他作品代为删除。
