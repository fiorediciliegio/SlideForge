# ADR-0068：页面创作附带本页原始配图

状态：已采纳

## 背景

仅传图片描述和文件路径时，HTML 创作会话无法核对画面，容易错误裁切、画圈或把示意图当成真实细节截图。

## 决策

首次页面生成（包括封面）和单页批量重新生成共用原图附件准备逻辑，按 `selected_image_ids` 顺序最多附带前 6 张。这是应用每次创作的附件预算，不声明平台整段会话的累计上限，也不限制用户选图数量。

保留当前图片 JSON 清单及所有已选素材，新增 `attachment_index`：附件编号从 1 开始，超过预算的图片为 `null`。清单和附件顺序来自同一份准备结果；任一必要素材缺失或上传失败会使本次准备失败，不跳过后重排。批量候选创建前准备一次，全部候选共享；同会话格式修复沿用已发送附件，新会话重试重新携带附件引用。

提示词将全量已选清单明确标为用户指定配图，必须全部清晰展示，包括 `attachment_index: null` 的素材。附件预算只限制原图视觉输入，不授权模型省略已选图片；模板参考和默认排版建议不得覆盖用户选图要求。生成结果不增加漏图检查或相应重试。

后端按有效目录中的素材标识解析原文件并验证真实路径归属，复用 Host Upload（宿主上传）和有效期缓存，以 `image_input` 用途上传原始字节。不复用受压缩及尺寸预算限制的 UI 预览，不将远程附件地址写入 HTML；页面仍引用工作区绝对路径。

提示词要求看原图而不是猜测描述，以真实对象为依据裁切和标注；未附原图的素材避免精确裁切、画圈，不得用无关区域或绘制图冒充真实截图。

页面精修、一键美化及自动布局修复维持只有附件 1（当前整页截图），明确区别于原始配图。大纲和批量重新生成共用的配图区域及选择器，在超过 6 张时显示四语轻提示，不拦截操作。

空描述素材同样进入全量清单及原图附件。生成前的可选描述准备不扩大本次 HTML 附件预算，也不删除失败图片；未附原图且没有描述时，只能依据真实路径和尺寸安排展示，不从标题猜画面。见 [ADR-0077](0077-image-candidates-and-deferred-descriptions.md)。

## 验证

覆盖前 6 张上限与乱序上传、全量清单和空附件、失败不降级、封面及普通页首次生成、批量候选共享附件、布局修复及精修截图隔离，以及原图上传和工作区路径边界。
