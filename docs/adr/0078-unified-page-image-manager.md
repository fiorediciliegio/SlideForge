# ADR-0078：大纲与单页批量重新生成共用配图管理窗口

状态：已采纳

## 背景

已有素材选择与关键词搜图分别打开弹窗，用户需要反复进出。新一轮搜索清空搜索弹窗的勾选，无法在同一次操作中组合已有素材、上传图片和多轮搜索结果。

## 决策

- 大纲详情和单页批量重新生成只提供“选择或搜索配图”入口，共用一个窗口。按钮沿用紫色强调色并配图片加号图标，旁边以“已有图片 · 上传 · 搜索”提示能力；窄屏自动换行，悬停反馈尊重减少动态效果偏好。窗口显示当前未保存编辑中的页码、标题、大纲摘要，可展开阅读全文及本页创作要求；不读取旧大纲替代当前编辑内容。
- “本页已选图片”独立展示本次选择草稿，打开时带入原有配图，支持大图预览和移除。下方设置“已有图片”“搜索图片”两个标签页，切换来源、筛选素材及开始新搜索均不清空选择。
- 已有图片继续显示正式素材及完整成功候选池，支持来源筛选、标题和描述过滤、跨页复用及其他页面使用提示。来源只在顶部筛选中展示，图片卡片不重复显示来源文字。上传入口位于这个标签页，保存成功后默认勾选；上传记录及搜索面板在切换标签时保持挂载。
- 关键词搜索沿用一次最多 20 个结果的独立任务。每次开始使用当前页面内容并创建新任务，不续跑旧任务。窗口内保留最近五轮搜索的结果供切换查看，关闭后销毁这份界面记录，不增加持久化历史入口。更早结果中已选图片继续保留在选择草稿中。
- 搜索结果只加入候选素材集合，勾选不下载作品原图、不应用到外层编辑。同内容按完整哈希合并来源、搜索词及 APS 引用，保留旧标识别名；搜索再次命中正式素材不会将它退回远程候选，不改写原有 AI 推荐判断。
- 固定底部只展示总图片数量、“取消”和“确认配图”。确认统一下载、核验、保存所选远程候选，全部成功才应用到外层编辑并关闭。保存反馈集中在确认按钮；部分失败保留选择并在已选图片及候选卡片标记，再次确认只处理失败项，也可移除失败图片。
- 搜索、取消收尾、上传及保存期间禁止关闭窗口；保存期间禁用选图和标签切换。搜索与上传期间可以查看另一标签，但禁止启动冲突操作或调整选择。离开页面取消本窗口拥有的搜索，迟到结果不修改新页面。
- 取消、关闭或 Esc 放弃本次选择草稿，不删除已经保存的素材。搜索候选仍沿用原任务保存；大纲配图仍需显式保存详情，单页候选仍需采用结果后才更新正式大纲和页面。
- 新文案沿用中、英、日、德四语消息类型与语言包。两标签页支持键盘切换，图片预览与窗口沿用原生模态框焦点管理。业务仍通过原有服务与 `PptBackend` 调用，不新增传输协议或描述模型调用。

本决策更新 ADR-0055、ADR-0065、ADR-0069、ADR-0070 和 ADR-0077 中的入口、确认按钮及窗口交互约定，素材存储和生成前补描述规则继续沿用。

## 验证

覆盖两处未保存标题与大纲回显、跨标签与多轮搜索保留选择、同内容去重与正式素材复用、四语确认状态、文件部分失败及重试、取消草稿、大图预览、忙碌关闭限制和离开页面后的迟到响应；沿用上传、搜索服务、大纲编辑、单页候选和国际化回归。

2026-10-09：上述相关回归 119 项通过，类型检查和 App 构建通过。严格校验仍将原有发布脚本的合法 `tool-id` 参数误判为拼写错误；额外运行的大纲创作要求测试有一项沿用旧版修复提示词接口，原提交中已存在。未启动开发服务器，未进行真实宿主浏览器联调。
