# 作品统一的页面尺寸

用户在首页、生成演示需求前选择页面尺寸。每份作品统一使用一种比例，默认 16:9；支持 16:9（1920×1080）、4:3（1440×1080）、9:16（1080×1920）和 3:4（1080×1440）。界面提供中英文名称，需求确认页展示所选规格。

比例保存在 `requirements.json` 的 `selections.aspect_ratio`。它是用户明确选择的生成规格，不由需求模型推断或覆盖。旧作品缺失此字段时按 16:9 读取。首次开始生成需求时，即使后续模型调用失败，也保留已选尺寸。已有页面源码的作品禁止更换比例；本轮不提供已生成作品的比例转换或混合比例文稿。

前后端共用 `executas/ppt-engine/src/slide-format.ts` 的尺寸表。HTML 使用 CSS 像素；PPTX 使用对应物理尺寸：16:9 为 13.333333×7.5 英寸，4:3 为 10×7.5 英寸，竖版交换对应宽高。PDF 使用相同物理尺寸。

可重建的 Deck Manifest（演示文稿清单）按需求投影 `aspect_ratio`，旧清单省略时默认 16:9。引擎生成的页面及整份静态 HTML 在根 `html` 元素上记录 `data-ppt-aspect-ratio`，用于截图、预览和导出；人工保存时以工作区需求重新确定尺寸，不接受编辑内容自行改变作品规格。组合整份 HTML 时拒绝混合比例。

母版、页面生成、精修、美化和布局修复均按目标画布创作；渲染外壳、静态化、布局检查、截图、预览、放映、人工编辑和导出使用相同尺寸。预览只做等比缩放，不能改变页面布局。

模板参考页仍只提供美学参考，不决定作品尺寸。个人模板的预生成母版仅在比例一致时直接复用；不一致时保留模板参考快照，并按目标画布重新生成作品母版。模板库本身不批量改写，也不为每个比例复制整套内置模板。

本决策替代 ADR-0034、ADR-0040、ADR-0049、ADR-0057、ADR-0059 中固定 16:9／1920×1080 的画布限制，其余页面源、静态快照和导出职责保持有效。

验证覆盖四种比例从需求、清单到真实浏览器渲染、截图边界、人工修订和 PPTX／PDF 页尺寸；同时检查默认比例兼容、非法比例及混合比例拒绝、个人模板比例不匹配和生成后尺寸锁定。
