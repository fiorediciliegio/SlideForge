# 大纲详情直接编辑顶部标题，并移除核心信息字段

## 背景

右侧详情重复展示页面标题，独立的核心信息字段增加界面密度，也与页面正文重复。用户要求标题在顶部直接编辑，页面类型可在标题附近选择，并从大纲及后续提示词中移除核心信息。

## 决策

- 顶部标题使用直接可编辑的文本控件，长标题自动换行；输入仍保存为单行标题。页码说明、紧凑的页面类型下拉框和关闭按钮组成顶部信息栏，标题在下一行独占可用宽度。打开详情时焦点落在顶部说明，标题仅在编辑时显示焦点边框；常规长标题自动增高，极长标题仍限制高度以保留正文操作空间。正文区只保留页面内容、本页创作要求和配图。
- 所有修改仍在详情内暂存，点击“保存修改”才持久化；取消或关闭丢弃本次编辑，保存失败保留编辑。输入法确认文字不触发提交。
- 从当前大纲条目类型、生成和改写协议、校验、持久化、修改预览、单页重新生成及整套精修中移除 `core_message`。后续页面生成和参考选择不再读取或传递该字段，也不从正文自动派生替代字段。
- 历史大纲仍使用现有版本读取和规范化机制：容忍输入中的 `core_message`，读取后丢弃并按现有机制保存规范化结果，不校验它的值。保留标题、正文原文、创作要求、配图、页面标识及确认状态，不拼接旧核心信息，不触发已有页面重写。
- `generation_notes` 仍仅用于大纲生成和改写时的依据说明，校验后丢弃。它不替代正文，也不成为新的持久化字段。
- 新增界面提示沿用现有中英文消息结构。

本决策更新 ADR-0065 的详情编辑布局、ADR-0053 的单页候选配置和 ADR-0066 对核心信息的约定；当前大纲的生成与精修协议均以本决策为准。旧任务状态机的 Page Plan（页面计划）属于独立历史协议，本次不修改。

## 验证

覆盖中英文详情编辑、页面类型选择、空标题拦截、取消、保存失败重试；验证无核心信息的大纲可以生成、保存、确认和重新读取，旧字段被丢弃且正文与页面标识不变，后续提示词不含该字段。运行前端和引擎类型检查、相关单测、构建与应用校验，不启动开发服务器。
