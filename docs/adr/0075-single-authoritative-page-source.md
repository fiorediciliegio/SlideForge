# ADR-0075：统一正式页面来源与预览重建

- 状态：已采纳
- 日期：2026-09-29
- 调整：ADR-0040 的独立人工正文、ADR-0072 的历史版本确认恢复规则。

## 背景

云端快照不保存可重建的 output 目录。恢复时，旧验收指纹与当前源码的路径等字节差异会阻止预览发布；作品列表又以整份预览文件是否存在分类，导致完成作品变成未完成。人工正文与 slides 同时存在，也增加了恢复、优化和导出的版本选择复杂度。产品不再需要人工编辑后的原版回滚。

## 决策

- `slides/<page_id>.html` 是唯一正式页面正文。人工保存、生成和采用候选都以该文件为正式内容。未保存草稿和未采用候选不进入它。
- 人工保存校验静态 HTML 后，以现有多文件发布事务同步替换源码与修订元数据。元数据只保留版本号和保存信息，不另存 base.html/current.html；编辑器移除恢复原始生成版入口。
- 旧人工修订首次读取时，先将规范位置的 current.html 与迁移标记事务性发布到 slides。保留修订版本号，清理旧的两份正文。迁移重复执行不覆盖新内容；旧正文缺失或越界时保留错误，不悄悄采用编辑前源码。
- 人工静态 HTML 可以直接作为正式页面使用，渲染器不向它重复注入页面外壳或执行引导脚本。生成的可执行 HTML 仍先完成浏览器静态化。
- 预览缓存按当前源码使用；缺失或版本不同就从当前源码重建。历史验收指纹不再决定能否恢复。仍检查重建期间源码与页面列表是否发生变化，避免发布过时结果。
- 重建不改变创作完成状态，不把未完成创作自动验收。已完成作品与预览产物是否存在分开表达；作品分类使用创作完成状态。
- 打开工作区不执行全稿预览修复，不等待浏览器渲染或图片、字体加载。缺失预览由后续预览请求准备，需要完整演示的导出操作仍执行必要的修复。
- 手动预览恢复同样使用当前已保存源码，不再从历史快照选择旧内容。优化、美化、预览和导出共享当前内容。

## 验证与边界

回归覆盖人工保存直接发布 slides、同版本并发保存冲突、旧修订迁移与重复打开、缺失正文保护、删除 output 后恢复、旧指纹失配、完成分类和静态页面外壳。

本改动不把失效的外部图片地址变成有效素材。页面源码引用的图片和字体仍必须可读取；预览重建失败不应改写作品的完成事实。
