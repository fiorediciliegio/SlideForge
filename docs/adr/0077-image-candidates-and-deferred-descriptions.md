# ADR-0077：完整图片候选、人工采用与生成前补描述

状态：已采纳

图片选择与关键词搜索已收敛到共用配图管理窗口，入口及确认交互以 [ADR-0078](0078-unified-page-image-manager.md) 为准；候选与生成前描述规则继续沿用本文。

## 背景

首次图片研究只自动导入模型入选的图片，人工选择器遗漏了已经成功获取但未推荐、未分析或超出研究附件预算的候选。搜索添加和手动上传还要求先完成描述，导致保存完好的原图因辅助模型失败而不能使用。

## 决策

- 候选可用性以成功获取、稳定 APS 引用、完整 SHA-256、受支持格式及有效字节数为准。候选从现有首次研究检查点和按页搜索任务读取，按内容哈希合并来源、搜索词和 APS 引用，不另建平行候选存储。记录随作品快照保存，需求重新确认时沿用研究目录重置。
- 人工选择器显示正式素材和完整候选池，卡片展示图片来源，不展示 AI 推荐或分析状态；原判断仍保留在候选元数据中。打开列表和预览只读取元数据、刷新地址。
- 勾选只更新弹窗内的选择草稿，不启动原图下载。点击“完成”后统一下载、校验并保存所选远程候选，按钮显示加载状态，处理期间禁止关闭、上传和修改选择。全部成功后才将正式素材标识应用到外层编辑并关闭；部分失败保留勾选并标出失败图片，再次完成只处理未成功的候选，也可取消勾选失败图片后继续。直接关闭弹窗放弃本次选择草稿，但不删除已保存素材。
- 素材选择和新搜索结果添加的保存反馈统一集中在确认按钮内，复用转圈图标及四语“正在保存图片”文案。保存不增加独立进度面板或上方处理提示；失败提示与搜索阶段进度继续由各自流程负责。
- 人工采用与 `use_in_ppt` 的模型判断分开，不能把未推荐改成模型推荐。未推荐及未分析候选的诊断文字清空，不能成为客观画面描述；已有空描述正式素材按内容哈希复用。上传素材仍优先，旧素材标识作为别名保持可解析。
- 搜索添加和手动上传不调用描述模型，原图保存成功即完成。空描述不影响大纲保存、确认、重开、预览、原图附件及候选创建和采用。按页搜索当前一次最多获取 20 个结果，不恢复旧版多轮研究流程；首页上传资料分析职责保持原有边界。
- HTML 生成前统一收集目标页面实际选用且缺描述的正式图片，按哈希去重，每批最多 6 张；14 张分成 6、6、2。使用现有无工具结构化会话与模型路由，每条客观描述最多 400 字符，并保持附件编号与素材映射。
- `IMAGE_NOT_AVAILABLE`（无法查看图片）进入统一会话有界修复，不额外叠加业务重试循环。单项、整批及辅助保存最终失败继续生成，保留已成功描述及全部选图。保存失败时当前内存成功结果仍可进入 HTML 提示词；取消信号必须停止会话及后续处理。
- 整份生成使用稳定事务 ID 保存已处理内容哈希，恢复和页面重试复用同次记录，新运行获得新记录。应用内另保留最近运行的成功描述和处理记录，辅助保存故障不会让当前运行重复消耗预算。整份准备写入影子工作区，与生成提交、放弃串行；放弃后的迟到写入被拒绝。正式候选及人工采用标记快照待同步，影子变更只在提交后成为正式内容。
- 单页多个候选使用当前未保存的选图，共享一次描述准备和一次原图附件准备；采用候选前不改正式页面或大纲。美化、布局修复和精修不增加补描述流程。
- 全部选图仍进入必须使用的 HTML 图片清单，原图附件仍只附前 6 张。空描述或 `attachment_index: null` 不授权省略图片；没有原图及描述时只依据真实路径和尺寸安排展示，不猜画面细节。不新增漏图检查或生成门槛。
- 业务调用继续经过 `PptBackend`、适配层及统一调用网关。新增 `app_outline_image_descriptions` 更新对应素材目录并保存运行记录，复用各目录的写入队列，不新增普通工具直连或业务传输协议。界面状态及说明提供中文、英文、日文、德文。

## 验证

定向测试覆盖完整候选及诊断隔离、列表和预览不导入、采用时文件校验、同内容复用和旧 ID、空描述保存及快照、6／6／2 分批及异步编号、真实统一会话的有界重试、部分成功、整批和保存故障降级、同次运行复用、取消与迟到写入拒绝、整份 HTML 顺序及全量清单、单页候选共享准备、四语忙碌及显式保存边界。

本地验证不包括真实宿主的 APS 长期保留契约、网络文件上传及浏览器联调。应用不全量下载或主动清理未采用的 APS 候选。
