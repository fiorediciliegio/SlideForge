# ADR-0063：统一 HTML 预览，整页截图仅作临时会话附件

- 状态：已采纳
- 日期：2026-09-18
- 后续调整：列表缩略图和候选 iframe 生命周期以 [ADR-0064](0064-webp-thumbnails-and-retained-candidate-previews.md) 为准；本文件保留当时决策背景。
- 调整：ADR-0017、ADR-0040、ADR-0053、ADR-0057、ADR-0060 中有关持久化截图和图片预览的约定。

## 背景

结果主预览已经直接展示静态 HTML，但生成、人工修订、封面及候选仍保存整页 PNG 或 WebP。它们可从 HTML 重建，长期保留会随作品与候选数量增加占用磁盘。

## 决策

1. App 普通生成、恢复、人工保存和候选生成只保存静态 HTML。正文图片、字体、模板参考与预设预览资源继续保留。底层显式图片导出能力不受此约定影响。
2. 结果页、放映、网格、缩略条、生成过程、人工编辑缩略图、批量测试、作品封面和候选统一读取 HTML。使用现有沙箱 iframe、APS 资源映射和完整响应 48 KiB 预算；封面读取第一页，候选通过作品、批次、候选标识定位。
3. 卡片进入可视区域后加载，离屏释放 iframe。可见卡片共用最多四路准备队列，完成或失败后释放名额。
4. 页面优化、布局修复、一键美化等会话需要图片时，从对应静态 HTML 按需截图。截图只写系统临时目录，上传后通过 `finally` 删除；失败也删除。后续截图请求清理超过 24 小时的异常退出遗留目录。会话上传引用可以继续复用，不承诺清理远端附件。
5. 预览版本包含 HTML 与本地图片、字体内容。截图前后和上传后校验版本，避免把改写前后的输入混入同一会话。人工修订保存后返回新预览版本。同批美化候选复用一次准备的源 HTML 和视觉附件。
6. `Page Progress` 的 `snapshot_source_sha256` 表示静态快照对应的源码版本；读取旧 `screenshot_source_sha256` 时兼容投影。旧截图路径字段可为空，不再作为页面完成、缓存命中或候选采用的必要条件。
7. 打开旧作品且所有当前页面静态 HTML 文件可用后，清理已知生成截图目录、封面与缩略图 WebP、有对应 HTML 的人工修订和候选截图。只处理工作区内已知路径，拒绝符号链接越界，不扫描正文素材。清理失败记录警告，作品仍可打开。历史 ZIP 归档不改写。

## 影响与验证

磁盘不再随普通任务累积整页截图。会话启动增加一次截图成本，HTML 卡片比图片占用更多浏览器资源，因此使用可见性卸载和有界准备队列。

自动化验证覆盖 HTML／素材版本变化、无 PNG 读取和候选采用、临时截图在成功／失败／版本冲突后的删除、旧截图清理边界与队列并发。真实浏览器中的字体加载、缩放和大量卡片滚动仍需实际页面验收。
