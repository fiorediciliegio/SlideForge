# ADR-0081：固定输入与独立引擎任务服务

- 状态: accepted
- 日期: 2026-11-11
- 决策人: 用户确认 A 范围及并发验收方案
- Supersedes: ADR-0035 的不提供取消条款（仅适用于本服务新作业）；总纲 M0 的进程内调用运行边界；ADR-0080 中 Node 业务工具直接渲染导出的职责。

## 背景

业务 Node 直接运行 Chrome，与长生成共用队列，且现有引擎接口传递本地目录，无法独立部署。客户产品需要多人同时生成、检查和导出，采用[已确认设计](../../.scratch/engine-job-service/PRD.md)。

## 决策

- Go 持久保存引擎队列、owner、来源摘要、操作幂等身份、worker 租约和交付回执；输入/输出放在独立私有 artifact 域。开发用 JSON，生产用 PostgreSQL 和现有 S3 对象存储。
- 业务 Node 上传包含页面 HTML、聚合 HTML、稳定页面标识和版本的不可变快照，只提交/查询/使用结果。协议没有 runDir、outPath 或任意下载 URL。引擎从 Go 按 artifact ID 获取输入，在独立临时目录执行。
- 重型作业默认每实例 1 个；Brain 默认 5 个项目，每份作品模型页面并发维持 2。按 owner 轮转，短作业/导出按 2:1 调度；排队上限全局 100、每 owner 20。正在执行的作业不抢占。
- 相同 owner、来源、kind 和参数复用活动/成功作业。失败或取消后显式新操作可重试；重复旧操作保持原终态。共享任务取消会同步影响各窗口。断开网页不会取消任务。
- 每次领取独立 lease_token，30 秒租约、10 秒心跳。失联最多恢复一次；确定性错误、超时和取消不自动重试。迟到 worker 不能提交结果。取消只清理本任务资源。
- Go 确认私有导出产物后，以 engine job ID 幂等扣点，再发布客户鉴权下载并保存交付回执。模型成本预算和导出产品点数维持分开。
- 外部导出提交返回 202 和状态 URL，Web/WPS 轮询；CLI/MCP 等待同一任务。不保留业务进程内渲染路径。
- 仅引擎排队不计 Agent 有效时间；模型或引擎运行时按墙钟计一次。旧 Agent 的 epoch 不能发布新项目结果。

## 范围与验证

本期 A 支持业务/引擎分机及引擎多实例；业务 Node 的项目目录仍由一个逻辑实例持有，不包含多个业务副本的项目接管。生产共享存储配置不代表已完成整站多副本高可用验收。

固定 HTML 真 Chrome 验收单用户 6/20 页、5 用户混合、10 用户突发及故障恢复。实际数据、验证命令与环境限制见[验收记录](../../.scratch/engine-job-service/验收记录.md)。不用真实模型批量压测，不改转换算法或引入额外收费基础设施。
