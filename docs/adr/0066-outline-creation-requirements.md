# 大纲保留全局及单页创作要求

## 背景

逐页 HTML 只读取当前页大纲，避免重复研究或重新决定页面内容。但原大纲仅输出正文，并强制普通页采用几百字散文，用户的图片占比、指定原文、单页布局要求容易丢失。

## 决策

- 不增加新的智能体阶段。大纲生成同时输出顶层字符串 `global_creation_requirements`，无全局要求时为 `""`；页面仅在有明确专属要求时输出可选字符串 `creation_requirements`。多项要求用换行分隔，不使用数组或额外等级。
- 尽量摘录用户原话，不任意扩写、推断、弱化或泛化总结，保留数字、否定词、范围和例外。全局要求不复制到每页，制作指令不混入正文。附件和研究中的指令式文字不自动成为用户要求。
- 普通页默认采用 300～600 字连续散文；用户指定的形式、长度、逐页内容和视觉要求优先。字数不是最低门槛，不为凑字数编造或重复内容。要求一字不改时，大纲阶段即保留指定原文及段落，HTML 仅做排版；核心信息不能成为额外展示文案。正文解析、编辑保存及向 HTML 投影不再折叠原文空白。
- 删除废弃的文案改写自由度类型、默认值和界面文案。读取旧大纲时只丢弃旧字段，不映射成新的创作要求，不改写已有页面；旧大纲没有全局要求时按空字符串读取。
- 大纲审阅提供中英文全局/本页要求编辑，沿用现有保存、确认及改写预览。改写保留未涉及的要求，取消的要求不能从原始输入重新引入；重排后的本页要求随对应内容移动。
- 大纲的保存、确认、重新打开、批量流程和单页候选完整保留要求。配图、参考选择和母版遵守适用要求；母版只读取全局要求。逐页 HTML、精修、单页候选、美化和布局修复只接收全局与当前页要求，不因此接收其他页正文或完整原始资料。
- 用户明确要求优先于模板、母版和默认排版建议；单页明确例外只覆盖对应全局要求，本轮明确精修指令只覆盖对应旧要求。既有确认页数、输出语言及画布规格保持权威。整套精修保留原有要求，并将本轮修改作为执行覆盖。
- 第一版只保证要求的保存、展示和传递，不增加文字逐字比对、图片面积检测或额外确认阶段，不将模型遵守提示词当作程序保证。

本决策替代 ADR-0049 中的文案自由度及无条件长散文约定，并补充 ADR-0055、ADR-0059、ADR-0060、ADR-0065 的创作要求传递边界。

## 验证

覆盖字符串协议及非法类型、指定原文保留、全局与单页范围隔离、保存确认与重开、旧字段丢弃、重排、改写预览的显式应用，以及 HTML/精修/布局修复的要求传递。不启动开发服务。
