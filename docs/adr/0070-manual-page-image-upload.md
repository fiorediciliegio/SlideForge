# ADR-0070：大纲与单页候选中的手动配图上传

状态：已采纳

上传入口现位于共用“管理配图”窗口的“已有图片”标签页；窗口交互以 [ADR-0078](0078-unified-page-image-manager.md) 为准。

## 背景

大纲详情与单页批量重新生成已有素材选择和按页搜图，但用户无法在当前编辑位置补充自己的图片。首页图片附件的会话同时负责全文转写、事实摘要和用途分类，且附件集合参与资料分析的新鲜度判断，不能直接把这套业务流程用于用户已经明确选定的配图。

## 决策

- 两处共用的“添加图片”弹窗增加“上传图片”，支持多选 PNG、JPG、WebP、GIF，逐张校验、保存，成功后立即可用。单张最多 25 MiB；每个作品的手动配图最多 50 张、合计 100 MiB，包含空描述原图。浏览器先校验格式和大小，引擎核验实际解码、文件类型和尺寸预算。
- 原图通过宿主上传传输，React 界面通过业务服务及 `PptBackend` 调用引擎。引擎独立保存到 `uploaded-sources/asset/manual/`，不写入附件索引、附件上下文或首次图片研究进度，不改变需求和大纲。目录只保存稳定元数据；文件位置按内容哈希派生，不持久化临时下载地址。
- 新原图文件名与搜索及其他上传配图统一为 `image-<SHA-256 前 16 位>.<扩展名>`；完整哈希继续用于素材身份及校验，不同内容占用同一短文件名时拒绝覆盖。目录中的可选 `file_name` 保存新文件名，缺少该字段的历史图片仍按完整哈希文件名解析，不迁移已有页面引用；作品快照保留此相对文件名，异地恢复时重新派生绝对路径。
- 上传入口不调用描述模型。原图保存成功后接入共用目录、附件及预览解析，立即默认勾选当前页，允许取消；空描述是正常素材状态。HTML 生成前只对本次实际选用且缺描述的图片按内容哈希去重、每批最多 6 张补描述。单图、整批及辅助保存失败仍继续生成，成功描述保留，取消必须停止。见 [ADR-0077](0077-image-candidates-and-deferred-descriptions.md)。
- 已有素材内容哈希相同时复用其标识，包含已有空描述搜索图，不重复创建原图，不改变已有配图引用。目录写入复用工作区上传写入队列，保存后标记正式作品快照待同步；快照包含所有手动原图及可选描述。
- 逐张上传和保存，文件失败可重试，单张失败不回滚其他成功图片。文件处理期间禁止关闭素材弹窗，包括 Esc；操作结束后可正常关闭。离开作品后完成的操作只归属原作品，不更新新页面的选择。
- 素材入库与页面修改分离。大纲详情仍需显式保存；单页批量重新生成只改变候选输入，采用候选之前不改正式大纲或正式页面。关闭编辑或取消勾选不删除素材。关闭自动图片研究不禁用手动上传。
- 新文案统一进入现有国际化语言包，中、英、日、德字段保持完整。

## 验证

覆盖独立存储与附件隔离、图片格式和大小校验、原图完整性、内容去重、并发目录写入、快照包含与异地读取、空描述保存和预览、文件失败重试、四语多图部分失败、处理中禁止关闭、显式保存边界，以及单页候选输入与正式大纲隔离。
