# ADR-0076：生成页使用紧凑的逐页状态卡片

- 状态：已采纳
- 日期：2026-09-30
- 调整：ADR-0072 中逐页生成详情的展示规则。

## 背景

生成页已经通过实时预览和页面状态展示结果与进展。“查看生成过程”展开后经常只显示由同一页面状态生成的记录，重复出现“已通过”和“已完成”；进一步展开也可能没有正文。两层折叠增加页面高度和操作次数，没有提供相应的信息价值。

## 决策

1. 移除逐页“查看生成过程”入口及其嵌套阶段卡片。每页只保留页码、标题和一个当前状态；沿用现有状态颜色与卡片样式，删除详情后自然收紧高度。
2. 最终失败摘要直接显示在对应卡片中，允许完整换行，不依赖展开操作。继续隐藏尚在自动重试或已经恢复的错误。
3. 总体生成进度、已通过／进行中／等待数量、实时与正式页面预览、停止和恢复操作保持原有行为。
4. 页面执行状态、恢复数据、运行内历史记录和诊断日志保持原有收集与开关规则。本次只精简展示，不删除生成、布局检查、修复或恢复能力。
5. 研究阶段的来源、图片、报告，以及需求、大纲和附件分析的过程展示继续保留。共用的阶段组件样式与文案只清理不再使用的逐页专用部分。
6. 同步移除中文、英文、日文、德文中的逐页详情入口和专用完成后缀，保留已有多语言状态与错误摘要。

## 验证

更新原逐页详情折叠测试，覆盖其他页面进度变化、当前页完成以及历史原文存在时仍只展示状态卡片。四种语言覆盖等待、创作、渲染、布局检查、布局修复、通过和失败状态；已有测试继续验证总体进度、研究详情、预览及停止／恢复操作。
