# ADR-0079：大纲卡片直接展示和管理本页配图

状态：已采纳

## 背景

大纲列表原来只显示图片数量，用户需要先打开页面详情，再打开配图窗口，才能查看和添加图片。用户希望进入大纲页即可看到本页配图，并从卡片直接选图。

## 决策

- 大纲卡片右侧按已选顺序最多展示三张缩略图，图片后始终保留浅紫色虚线加号。没有图片时只显示加号；超过三张时在第三张叠加剩余数量。三张只限制卡片展示，不截断已有选择或限制配图数量。
- 点击缩略图沿用按需加载的大图预览；点击加号直接打开 ADR-0078 的共用配图窗口，无需先打开详情。窗口读取当前草稿中的页序、标题、正文、创作要求及完整配图选择。
- “确认配图”只更新该页在当前大纲草稿中的图片标识，卡片立即回显，仍需大纲底部的保存或确认操作才持久化。其他未保存的标题、排序和创作要求一起保留；取消、关闭或 Esc 不应用选择。
- 上传或采用成功的素材即时合并到当前图片库，刷新目录期间仍可显示；素材保存与大纲保存保持独立。工作区切换时销毁配图窗口及临时编辑状态。
- 大纲区域最大宽度由 1200 调整为 1280 像素，卡片增加留白。窄屏将图片区移到标题下方并允许缩略图收缩，避免标题和加号溢出。拖动、键盘排序、详情和更多菜单继续沿用原交互。
- 按钮及剩余图片提示补齐中、英、日、德四语，沿用现有图片服务和 `PptBackend`，不增加后端协议。

本决策更新 ADR-0065 的列表展示约定及 ADR-0078 的大纲配图入口和应用位置；详情编辑与单页候选的保存语义继续沿用。

## 验证

覆盖四语入口、直接打开配图窗口、确认后更新草稿并显式保存、保留其他未保存修改、取消选择、完整保留超过三张的配图、大图预览及工作区切换。沿用图片选择器和国际化回归、前端类型检查和构建，不启动开发服务器。
