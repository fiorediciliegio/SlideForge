# 从用户 PPTX 创建个人 HTML 模板

个人模板沿用 Visual Style Preset（视觉风格预设）的参考页语义，并额外拥有预先生成的视觉母版。它属于应用级资源，可供多个作品选择；不会进入上传资料的事实分析链路，也不恢复旧的 Markdown 风格画像流程。

每次创建只接收一个非空、最大 20 MiB 的 PPTX。应用上传文件后，创建仅允许 `doc_read` 的 Agent Session（智能体会话），明确要求读取上传后的 HTTPS URL，返回原文件中 1 至 6 个不同的物理页码。解析失败不能猜测页码。引擎使用已有 `pptx-svg` 只渲染这些页，保留原始页码；旧的整份文稿 80 页限制不限制所选页面的页码。

母版会话接收全部选中页的图片，输出完整 HTML。随后每页使用独立会话，以一张原页图片和母版 HTML 生成模板参考页，同时最多运行三个页面会话。HTML 提取、同会话简短修复和基础设施重试沿用统一 AgentClient；模型不写磁盘。引擎保存原始 HTML，复用正式页面的渲染外壳、静态化和截图能力生成预览。最后一个会话读取生成后截图，为模板生成名称、整体描述和逐页一句话描述。

资源位于 `getPptWorkspaceRoot()/user-templates/<id>/`，包含原始 PPTX、选中页 PNG/SVG、母版与参考 HTML、预览和模板元数据。只有母版、全部选中页及其预览、完整描述均可用时才发布。未完成的模板保留为草稿；继续创建时复用已保存的选页、母版和成功页面。已发布模板不可通过创建接口覆写。

前端通过 `PptBackend` 调用专用工具。HTML 和 JSON 通过 Host Upload（宿主上传）传递，文件返回使用上传引用，避免把整套模板字节塞入工具返回。页面提供独立“我的模板”入口，首页提供“内置模板／我的模板”分类，并沿用中英文国际化消息。

确认演示需求时，将个人模板的母版和参考 HTML 一并复制到作品，形成固定快照。已有母版直接满足生成准备条件，跳过母版生成和母版美学参考选择；逐页生成仍各选一个主导美学参考。改选内置模板会清除旧母版，恢复原有母版生成流程。模板示例里的文字与数据始终不构成新作品的事实依据。

本功能首先提供运行时工作空间中的持久化个人模板库，不新增个人模板库的跨设备同步协议。作品自己的模板快照仍随现有作品快照流程保存。
