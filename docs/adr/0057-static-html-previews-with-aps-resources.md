# 使用静态 HTML 主预览与可复用的 APS 资源

> 后续调整：页面提前展示与前台准备名额以 [ADR-0072](0072-progressive-html-preview.md) 为准，不再等待 iframe `load` 后才展示。

主预览、放映和单页优化的视觉预览改为显示已经成功渲染的单页静态 HTML。生成过程中的已渲染页面也使用这一路径；流式 HTML 仍是临时的创作反馈。存在人工修订时，预览读取其最新 `current.html`。不重新执行 Agent 页面源码，不更改正式 HTML、截图或后端导出输入。

## 传输

新增 `app_get_workspace_page_html`，只接受工作区与页面标识，以及可选的预期预览指纹。后端从页面状态解析当前静态文件，校验路径归属与版本。React 页面只通过 `PptBackend` 获取解码后的 HTML。

按完整业务响应序列化后的 UTF-8 字节数应用 48 KiB 内联预算：

1. 普通文本能放下，直接返回。
2. 否则使用 gzip 无损压缩及 Base64 编码，完整响应能放下时内联返回。
3. 压缩后仍超限，通过现有 Host Upload 的协商、PUT、确认流程上传文本，返回引用。

原始 HTML 上限为 64 MiB，前端流式解压和下载均校验声明大小并提前中止超限内容。Base64 的体积开销计入预算，不依赖 HTTP 自动压缩。上传分支需要浏览器可跨域读取的 HTTPS 文本地址；不回退到本地 HTTP 或超大 RPC。

这是 ADR-0017 中文件固定走上传规则的一个明确例外，仅适用于此有界 HTML 预览协议。

## 图片和字体

页面源码继续保留现有本地路径约定。后端使用 HTML 与 CSS 解析器创建展示派生内容，处理图片属性、候选图片集、SVG 图片引用、CSS 资源地址及本地字体。只允许工作区已有图片素材目录和 `fonts/` 中的真实文件，拒绝通过符号链接越界。大型内嵌图片或字体也可外置；小型数据 URL 保留。普通 HTTPS 外部引用继续沿用。

独立资源按 SHA-256 内容指纹发布到当前用户 APS Files 命名空间下的 `ppt-app/preview-assets/<sha256>.<extension>`。JPEG 扩展名归一化为 `.jpg`。相同资源的并发发布串行协调，同一次页面请求中的重复引用共享解析结果。

本地工作空间根目录下的 `.preview-resource-index/<sha256>.json` 持久化内容指纹、APS 稳定路径、作用域、大小、类型和确认信息。它是可重建的传输索引，不属于作品内容，不进入快照或触发作品同步，也不保存签名下载 URL。即使没有本地记录，确定性的 APS 路径仍可复用已有对象。

每次需要新的资源地址时，通过当前认证用户的 APS 文件列表检查对应对象，再获取下载地址；本地索引不充当跨账号或跨环境的授权依据。对象缺失才上传；权限错误、超时或无法理解的服务端响应不会被当作缺失。地址过期只重新获取地址，不重新上传已有文件。图片内容发生变化时使用新的内容指纹。

APS 下载地址响应中的 `expires_at` 可能是没有时区后缀的 UTC 日期时间，例如 `2026-09-14T10:20:01.188432`。APS 客户端将这种格式统一为带 `Z` 的 UTC 时间，避免由机器本地时区解释；已经带时区的值保持原语义。有效期以实际响应为准，不以请求的 3600 秒代替（实际环境可能只返回约 300 秒）。缺失、无法解析、已经过期或剩余不足一分钟的预览资源地址仍拒绝使用。

展示派生内容中的临时 URL 不回写源 HTML、人工修订或正式 `deck.html`。后端截图和导出保持本地资源语义。资源镜像属于应用内部传输文件，不产生“我的文件”导出记录；本次不引入跨作品共享资源的自动删除策略。

## 前端展示与缓存

主预览不再以截图上传成功为前提。页面元数据就绪后即可读取 HTML，缩略图独立补齐。结果页在完整页面元数据就绪后自动预取全页 HTML，每个预览会话最多同时获取 10 页，并最多同时准备 4 个固定 1920×1080 iframe。当前选中页优先，其次按距离加载相邻页（同距离先下一页），再处理剩余页；切页会重新安排尚未开始的工作。获取与 iframe 准备交叠执行，全部页面无需被点击即可进入预览会话。其他单页预览入口仍按访问加载。预览会话保留所有已准备的 iframe，根据容器缩放，禁用脚本与交互，设置资源加载 CSP 并移除活动内容。已加载的非当前页使用 `display: none` 隐藏，切回时直接显示；暂不设置页面数量上限。新页面以 `visibility: hidden`、`display: block` 准备布局与资源，完成 iframe 加载后再切换，期间保留旧画面并显示加载提示；晚到的请求不抢占当前选择。单个 iframe 加载超过 30 秒会释放准备名额并进入现有可重试错误状态，不阻塞其他页面。单页新版本准备好后替换该页旧版本，其他页继续复用。

HTML 文本缓存按工作区、页面和版本隔离，最多 12 项、8 MiB；请求可合并。文本缓存最多五分钟，并在资源 URL 过期前一分钟失效，只用于需要新建 iframe 时的传输复用。获取完成但尚未创建 iframe 的 HTML 由当前会话暂存，创建前再次检查资源 URL 有效期，过期则重新获取。页面列表变更会丢弃已删除页和过时的待处理版本；已发出的请求允许结束，但晚到结果不能复活已移除的版本。离开作品后不再调度新工作。上述文本缓存限制不约束当前会话待渲染 HTML 和已加载 iframe 的总内存，也不淘汰已经加载的 iframe；已加载页面不因 URL 到期而定时重建。失败显示中英文可重试状态。结果页在同一作品的其他操作页面期间保持隐藏挂载，返回结果页仍可复用；返回“我的作品”、切换工作区或卸载预览会话时释放对应 iframe。网格概览、缩略图和作品封面仍使用图片。

页面成功产出静态 HTML 与 PNG 的原有契约继续有效。AI 优化和视觉检查按需使用当前截图作为原生会话附件。截图上传与主预览传输分离。

本决策替代 ADR-0034 的“主预览使用截图”约定。ADR-0021、ADR-0049 的静态化及后端导出边界继续有效。人工编辑器也复用这里的 APS 资源与有界传输，具体保存、反向转换和旧修订迁移规则见更新后的 ADR-0040；页面源码和人工修订仍分别保留。

## 验证

覆盖中文与 JSON 转义预算、三种传输路径、错误压缩与解压限额、HTML/CSS/候选图片/SVG 资源替换、路径越界、APS 并发去重、重启后复用、对象丢失与权限错误、人工修订优先级、页面指纹冲突、前端缓存与缩略图故障隔离。补充验证全页无需点击即可准备、获取与渲染的并发上限、跳页后的优先级、等待期间链接过期、旧版本晚到与页面删除，以及失败释放准备名额。真实 Host 的 APS URL、CORS、字体加载及高像素密度屏幕显示效果需要在运行中的 App 中验证。
